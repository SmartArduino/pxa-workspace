# 官方板级固件 0.7.1

本版内嵌 **PXA 0.7.0**，六种官方板型均预装 **商城 0.9.3 / sequence 33**。
板级固件发行号由 `firmware/VERSION` 管理，PXA 发行号仍由
`deps/pxa-system/VERSION` 管理；产品集成可独立设置 `PROJECT_VER`。
应用兼容性依据 PXA Host 的 Core、服务、包格式及执行引擎能力，不比较整机固件版本。

## 保留数据升级与商城更新

分区布局相同的设备可只更新 app 镜像，保留已安装的应用、商城、存档和设置。
升级后联网打开原商城并检查更新，即使保留的是商城 0.9.0，也能按实际
PXA 能力获取商城 0.9.3。注意：0.7.1 能正确发现更新，但旧 `pxa-state`
安装目录及预装商城的更新预检仍可能返回“不支持应用安装”；此问题由
0.7.2 修复。商城更新仍需用户在商城内发起，不在开机时后台覆盖。
旧固件若没有此能力声明路径，仅靠服务器更新无法获知真实的 PXA 能力；
需要先更新固件，或通过 PXADB 安装兼容的新版商城。

Host 仅在官方 HTTPS 商城的目录、应用详情和检查更新请求上附加
`X-PXA-Host-Profile`。该值是已发布的不可变 PXA 能力配置，独立于整机版本，
也不是设备认证凭据。服务器允许同平台 Host 配置纠正旧商城内置的查询配置；
未知、非公开及跨平台声明会被拒绝。旧设备不携带此声明时，仍按原配置筛选。
包签名、发布者身份、升级序号和安装能力检查保持生效。

完整镜像用于首次安装，会重写数据分区。Mosaico 与 Korvo 从旧 4 MiB
应用分区迁移时仍须先备份再迁移；不能将新 app 镜像写入不匹配的分区布局。
各板型归档中的说明和 `flash-map.json` 给出准确分区、版本及文件摘要。
