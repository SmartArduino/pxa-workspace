# 内置 UI 开关与裁剪验证

2026-10-14：继续检查关闭内置设置后的其他组合。以下修复位于当前源码，
不会修改已有 0.3.0 标签、Release 或产品工程已经锁定的 Host SDK 归档。
锁定旧归档的产品需要生成并安装新的 SDK 才能获得后续修复。

## 开关的范围

| 开关 | 关闭后的行为 |
| --- | --- |
| ESP `CONFIG_PXSYS_REFERENCE_UI` | 不创建 reference UI、UI 字体和 viewport；系统服务、Guest 渲染和运行时继续可用。`system_ready` 收到的 UI 指针为 NULL。产品自行提供 UI，不自动启动历史版本界面。 |
| `PXSYS_REFERENCE_UI_BUILTIN_SETTINGS` | 裁掉内置声音、设备信息、应用、文件和 Wi-Fi 详情页。Home、设置入口、外观、语言、键盘偏好、状态栏和导航栏独立保留。网络详情使用产品提供的 network-settings 角色。 |
| `PXSYS_REFERENCE_UI_WIFI` / `CELLULAR` | 独立控制对应状态图标和设置行；可以分别关闭，与内置设置开关独立组合。 |
| `PXSYS_REFERENCE_UI_BATTERY_PERCENT` | 控制电量数字；关闭无线 UI 后仍可显示。 |
| ESP 状态栏、导航栏、返回手势开关 | 关闭对应功能后，不再向 Guest 发布该功能的边缘预留。屏幕物理安全区和圆角信息继续发布。 |
| 运行时 `config.features` | 控制角色注册。关闭 Home 后仍能启动其他角色；显式调用 Home 接口返回 NOT_FOUND。 |
| LVGL snapshot / pinyin / K9 | 快照不可用时卡片最近任务回退为列表；拼音或九键不可用时保留完整键盘。 |

## 发现并修复的问题

1. 内置设置关闭、无线 UI 保留时，网络行引用被裁掉的 Wi-Fi 点击回调。
   现在按可用实现选择回调和上下文，保留外部角色入口。
2. 两种无线 UI 都关闭、电量数字保留时，电量标签宽度变量仅写入而不使用，
   导致 `-Werror` 编译失败。现在仅在无线图标确实需要排布时测量宽度，
   同时省去该组合的一次立即布局计算。
3. 内置设置关闭后，角色过滤误删状态栏和导航栏，导致启动找不到角色。
4. 运行时禁用 Home 后，启动函数仍尝试打开 Home，导致其余 UI 无法启动。
5. 配置卡片任务视图、关闭 LVGL 快照时，列表回退路径没有编译按钮函数。
6. 关闭拼音或九键模式后，九键专用关闭回调未裁掉，导致严格编译失败。
7. ESP 集成未使用 UI 总开关，关闭后仍创建 UI 和字体。现在按该开关创建，
   同时更新 Kconfig 过时的历史界面说明；默认启用 reference UI，现有板子
   显式设置为启用的配置保持一致。
8. ESP 显示信息发布始终预留状态栏和导航区域，未遵守对应功能开关。
   现在分别发布状态栏、导航栏和返回手势预留；总开关关闭时全部为零。
9. 关闭动画后，Home 翻页仍强制播放滚动动画，Toast 也总是从透明渐入。
   现在翻页遵守动画策略，关闭动画时 Toast 立即完整显示。

修复没有增加帧缓冲、默认缓存或动态容器，也没有改变 Guest ABI。
新增编译矩阵和回归程序只进入原生测试构建。

## 验证结果与边界

- 80 种 UI 配置通过实际对象文件编译，开启 `-Wall -Wextra -Wpedantic -Werror`。
  覆盖内置设置、Wi-Fi、蜂窝、动画、列表/卡片、快照及其他开关的代表组合；
  这不是所有布尔开关的穷举。
- 31 项原生 CTest 通过；另外通过已有应用手势、系统手势及 LVGL renderer
  三项相关回归。新增功能掩码、无快照、无拼音、非九键和关闭动画回归。
  每个功能测试遍历
  Home、设置、状态栏和导航栏的 16 种掩码，并检查角色注册、界面启动、
  设置、主题更新、最近任务和重复销毁。
- ESP 显示信息发布函数使用实际函数源码进行原生探针验证：32 种开关组合，
  每种覆盖矩形、圆角矩形和圆屏，检查预留、物理安全区和圆角信息。
  探针替代了设备 API，不能代替 ESP-IDF 集成编译和真机验证。
- 独立编译 UI 与 IME 的拼音关闭、完整键盘、九键三种配置，并分别开启和
  关闭内置设置，避免只在默认配置下通过。

原生回归已纳入 `deps/pxa-system/ui/reference/lvgl/CMakeLists.txt`。
在启用 reference LVGL 和原生测试的构建目录执行：

```sh
cmake --build <native-build-dir> --parallel 4
ctest --test-dir <native-build-dir> --output-on-failure
```

本次没有运行 ESP-IDF 构建或刷机，仍由产品工程维护者进行设备编译验证。
完整 UI 总开关关闭时，锁屏、电源菜单等 reference UI 能力也随之不可用，
产品需要提供自己的入口；仅关闭内置设置不会关闭这些系统界面。
