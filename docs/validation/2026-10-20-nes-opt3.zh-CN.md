# NES 中文菜单、声音状态及系统浮层底图修复

固件 **0.4.0** 与应用 **0.1.21 / release_sequence 23** 已在用户明确要求“更新并测试”后安装到 PAI Touch。已完成音量浮层白屏回归、中文菜单、声音启用、颜色和实机帧率检查。后续按用户要求加入图标与 PXA i18n 的 0.1.22 交付状态，见[国际化与性能分解报告](2026-10-20-nes-i18n.zh-CN.md)。

## 已安装的用户游戏

本轮将先前实机验证的 0.1.19 ESP32-S3 AOT 重新签成原身份 `pxa-nes` / release 21，加入用户提供的 ROM。AOT 与已验证测试包逐字节相同，ROM 哈希与原文件一致。未换签名发布者或清除应用数据。安装前查询了设备、应用列表和屏幕；原正式身份下的重装机兵电池 RAM 文件尚不存在，未使用临时测试身份的存档覆盖。启动日志确认 mapper 74 / NTSC 60，显示重装机兵标题。随后用户自行操作了菜单，最终状态会随试玩改变。

用户询问旧版声音按钮无反应时，读到宿主已有 16,392 字节音频会话分配、预算拒绝及分配失败均为 0。旧版启用后按钮一直写着 ENABLE SOUND，暂停时也不再生成 PCM；因此缺少状态反馈，用户还需返回游戏。该内存快照不能代替扬声器听感或声学延迟验证。

## 声音与中文 UI

- 声音按钮显示关闭、开启中、已开启及失败，支持关闭及重试；处理同步请求错误、异步拒绝、格式不匹配、写 PCM 失败和权限撤销，关闭相关句柄并保留正常重试路径。
- 游戏列表、暂停菜单、声音设置及悬浮按键汉化；马里奥与重装机兵显示友好中文名。菜单采用暗色背景和高对比主操作。
- 124 个 Unicode 字形的单色点阵表约 **4,464 字节**，来自 Noto Sans CJK SC Regular / SIL OFL-1.1，授权、源字体哈希和生成脚本随源码保留。另有少量代码及 ASCII 字库开销。该子集不是完整汉字库，未知字形显示方框。
- 菜单仅需重绘时绘制；悬浮按键字形在初始化时写入覆盖图。游戏帧继续使用原 RGB565 查找表及脏块绘制，不逐帧解析中文，不加载完整运行时字体，不新增游戏帧缓存。游戏采样和调色板不变。

## 白屏原因与固件修正

旧 ESP 后端对 GuestMapped 帧调用 release_frame 后立即发布归还事件并清空 current。此时系统音量条、权限对话框或其他浮层独立触发 LVGL 刷新，可能没有任何可借用的游戏底图，导致底层空白背景露出。这是宿主的映射帧寿命问题，单改 NES 调色板或只更新 `.pxa` 不能解决。

修正将最后一帧保留为 current，直到替换帧开始消费时才归还旧缓冲；Guest 可在宿主旋转替换帧时绘制旧缓冲。重复读取 current 不重复增加 presented 或归还统计。不保留已归还给 Guest 的裸指针，不增加像素拷贝、Surface 分配或帧缓存。

这一改动保留一张映射缓冲，改变了归还时机。新固件下重装机兵实游戏仍维持约 60 模拟 fps；不同场景的旧版本数据不构成严格性能 A/B，不据此声称提速或完全无代价。

修正在以下文件：

- `firmware/components/pxa/src/services/pxa_esp_surface.c`
- `firmware/components/pxa/include/pxa/pxa_esp_surface.h`
- `firmware/components/pxa/tests/pxa_esp_surface_backend_test.c`

PAI Touch / ESP32-S3 固件已完整构建成功，二进制 3,596,576 字节，位于 `local/nes-work/opt3-20261020/firmware/pxa-nes-overlay-fix.bin`。分区表与实机所报告构建提交 75673a9 的板级分区表逐字节相同：应用 0x10000 / 0x6f0000，数据 0x700000 / 0x900000。已仅写入应用分区；刷写后、首次启动前逐字节核对 bootloader、分区表、NVS 与整个 pxa_data 分区，均与备份相同。重启后再次读取应用存档，哈希与刷写前一致，见 `device-update/flash-preservation.json` 和 `saves-after-firmware.json`。完整闪存备份及存档内容仅保留在本地忽略目录。

## 继续优化的边界

新增按 8 行区域跳过已脏图块重复比较的实验路径，保留完整历史像素更新以避免变化抵消产生残影。以 `NES_EXPERIMENTAL_TILE_SCAN` 编译时启用。不同原生微基准出现收益与回退，并受并发编译、CPU 频率等影响；不将其折算成 LCD FPS。**交付包默认不启用该实验，保留已在实机测过的 0.1.19 检测路径**，候选源码和测试保留供后续 ESP32-S3 对照。

| 场景 | 模拟 fps | LCD 全帧完成 fps |
|---|---:|---:|
| 重装机兵标题 | 60.04 | 12.66 |

每个场景采集三段完整约 5 秒模拟遥测；LCD 探针另含预热窗口，按各自帧数和时长计算。最大积压不超过 1 帧，Guest 音频丢采样为 0。LCD 数字包含相同内容的重复传输，不等于独立变化帧或光学扫描 Hz。正式存档在收尾审计发现缺失后，已按刷写前备份恢复并逐文件核对；实游戏输入使用相同 AOT 的独立测试身份。

## 验证

- 默认及实验绘制路径各 6,240 帧与独立完整 RGB565 参考逐像素一致，涵盖四种尺寸、双缓冲、对齐、取消变化、按键状态及失效恢复。
- 前端声音通过实际 PXA 消息编码测试：重复点击、开关、拒绝后重试、同步及异步失败、格式、背压、写入失败、撤销及迟到结果清理。
- 中文 UTF-8 正常及截断/非法输入、文本宽度、边界裁剪、保护字和完整字形截断检查通过。
- 补充模拟音量条的半透明系统平面回归：不再提交 Guest 帧，连续 8 次合成时透明像素保留游戏底色、不透明像素覆盖正确；浮层消失后仍可读取同一底图，统计保持 32 次呈现、31 次归还和 1 张空闲缓冲。宿主 ASan/UBSan 全套通过，见 [补充日志](nes-opt3-20261020/host-tests-volume-alpha-asan.log)。实机另连续三轮展示/关闭音量条，静止菜单在音量条区域之外像素完全一致；动态游戏也未再白屏。截图元数据确认浮层时走 composed、消失后回到 surface。
- 上述前端回归以 ASan/UBSan 运行通过；ESP 宿主回归及 ASan/UBSan 全部通过，包括无新提交的浮层重绘、归还顺序，以及两张映射缓冲的 32 次连续替换、每帧 3 次重复预览。
- 桌面以实际签名 AOT 运行重装机兵，验证声音开→关→开、中文菜单、手柄活动隐藏及触控恢复。SDL 使用 dummy 音频输出，没有验证物理扬声器。权限请求完成不等于可见授权对话框已人工验收。桌面音量键请求没有出现可见音量条，不计作实机浮层验收。
- 自行启动的模拟器和服务已结束。SIGTERM 后产品模拟器仍返回 -6，与此前已知收尾问题一致；未把自然关闭计为通过。
