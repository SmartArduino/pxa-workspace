# Korvo NES、颜色与多点调试实测

2026-10-20，`esp32s31-korvo-1`，800×480，串号 `30:ed:a0:f3:de:10`。运行 NES 0.1.24、release 28，用户提供的马里奥 PAL ROM（mapper 0，50Hz）与重装机兵汉化 ROM（mapper 74，60Hz）。ROM 未加入验证文档目录。

**Surface 尺寸限制解除、黑边显示、像素颜色和五点调试验证通过；整体满速目标尚未完成。** 马里奥模拟速度不足，重装机兵在所测开场对白场景维持约 60Hz，但显示更新远低于 60fps。

## 显示与颜色

NES 保持原始 256:240 像素比例。Korvo 使用 400×240 Guest 画布，游戏内容 256×240 居中；Host 整数 2 倍呈现，屏幕中游戏为 512×480，两侧各留 144 像素黑边。半透明按键覆盖整个画布，输入先将 UI dp 按 `density_q16` 转回面板像素，再转换到 Guest 画布。

首次硬件无损截图发现 PPA SRM 放大产生插值：与参考图比较只有约 75.8% 像素完全匹配，出现 43,830 个非调色板像素。现在 Guest 映射帧的放大采用 CPU 整数最近邻，原生 raster 场景仍可使用 PPA。CPU 路径将源行展开到 1,600 字节栈内暂存，再复制重复行，避免重复展开和逐像素小写入 PSRAM；没有新增整帧缓冲。

最终固件的静态标题无损截图中，**180,964 / 180,964 个被比较像素完全匹配 FCEUX 参考 RGB565，非调色板像素为 0**。排除按键区域、顶部 HUD 和底部系统提示条；这是帧缓冲颜色验证，不是 LCD 光学校准。[最终对比结果](nes-korvo-20261020/device-colors-final.json)

![最终固件，最近邻放大与黑边](nes-korvo-20261020/device-final-metal-title.png)

Guest 视频缓存对比覆盖 7,800 帧；实际 `ComposeRgb565` 函数另通过 168 组 ASan/UBSan 用例，包括裁剪、居中、源行间距、遮挡和 1/2/4 倍缩放。[绘制测试](nes-korvo-20261020/test-scaling.log)

Surface 服务不再以 320×240 或面板尺寸作为准入上限；800×480、1024×768、65535×1、1×65535 的 Host 双缓冲已在实机创建并释放。溢出请求正确拒绝。详见 [Surface 专项报告](2026-10-20-surface-geometry.zh-CN.md)。

## 最终固件帧率

声音开启，按键默认 38% 不透明度，显示策略每帧允许绘制，调度器根据积压跳过绘制。马里奥进入 1-1 并注入 RIGHT+A，重装机兵进入新游戏开场对白。每款游戏采集三个约 5 秒模拟窗口；显示完成计数覆盖整个约 30 秒窗口（含 12 秒预热）。截图、文件和内存查询不在显示计数窗口内。

| 游戏与场景 | 模拟 fps，加权平均 | 三段模拟 fps | 显示完成 fps | 目标 |
|---|---:|---|---:|---|
| 马里奥，1-1 RIGHT+A | 38.18 | 40.15 / 34.28 / 40.10 | 3.69 | 未达 PAL 50Hz |
| 重装机兵，开场对白 | 60.04 | 59.96 / 60.03 / 60.10 | 6.08 | 本场景模拟速率通过 |

显示完成来自面板完成回调时间及 `PERF START display` 的完成次数/设备时间窗口，不是 Guest 提交次数，也不是面板持续扫描的物理刷新率。此前 Korvo 直刷只记录 Surface 完成，遗漏 display 模式；本次已补齐直刷完成事件。

[马里奥原始结果](nes-korvo-20261020/device/mario-final/results.json)、[重装机兵原始结果](nes-korvo-20261020/device/metal-final/results.json)、[版本及汇总](nes-korvo-20261020/summary.json)。

马里奥每帧内核耗时约 19.2～22.9ms，积压从 345 增至 473 帧；仅取消尺寸上限或跳过显示不能解决这个瓶颈。重装机兵内核约 12.6ms，但精确最近邻的 Host 呈现仍约 13ms。旧 PPA 插值路径在同类开场场景可提交约 16fps，但颜色不准确；本次优先保留准确颜色。行复用减少了重复工作，**本轮没有证明整体帧率提升**，不能宣称完成性能目标或兼容所有游戏。

音频日志确认非零 PCM 已进入 DMA，观察到的 DMA 写入错误为 0。马里奥三个窗口 Guest 丢样均为 0；重装机兵为 42 / 0 / 0 个采样。该计数不覆盖所有可能的宿主欠载，本次没有做物理听感验收。

## 调试多点触摸

Korvo 实机五点测试通过：五指同时按下/移动、单独 UP、单独 CANCEL、全部取消、快速 DOWN/UP 边沿以及超时取消。取消使用 `lv_indev_wait_release()`，修正了原先重置 indev 时 Guest 收不到 CANCEL 的问题。[结果](nes-korvo-20261020/device-multitouch.json)、[事件日志](nes-korvo-20261020/device-multitouch.log)

GameKit 与 Watcher 增加五个调试触点，并完成交叉构建；本轮没有刷写这两块设备。PAI Touch、Mosaico 原有两个触点继续按各自能力报告。桌面调试支持五点，客户端读取设备能力确定上限。调试注入数量由 `INPUT CAPABILITIES` 报告；物理触点能力取决于各设备的触控硬件。
