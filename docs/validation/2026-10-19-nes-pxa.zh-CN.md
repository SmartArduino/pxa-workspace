# PAI Touch PXA NES 验证记录

交付版本 **0.1.12 / release_sequence 13**。源码位于 `local/pxa-apps/nes/`，签名多架构安装包位于 `local/app-output/pai-touch/pxa-nes.pxa`，包含 ESP32-S3 和 Linux x86_64 AOT。已安装到 PAI Touch，最后重新启动并停在暂停菜单。设备原有浏览器应用仍在，没有更新固件或格式化存储。

本轮结论：**随包诊断 ROM 在 PAI Touch 开启声音时平均执行 59.8798 个模拟帧/秒；显示独立跳帧，未持续积压模拟时间。** 这证明了当前前端、计时、渲染和音频链路可以完成该负载，不代表任意商业游戏都能满速或正确运行。

## 来源及实现

内核来自 [Retro-Go 固定提交](https://github.com/ducalex/retro-go/tree/4ced120669750ca7228fd0414211430c1d923166/retro-core/components/nofrendo) 的 Nofrendo。保留原作者、许可证及 GPL/LGPL 文件声明。前端提供 ROM 列表、双手柄端口、屏幕触控、暂停、音频权限和电池 SRAM 保存。随包唯一 ROM 为自行生成的 CC0 `pxa-demo.nes`：蓝色棋盘、可移动精灵、按 A 改红色、固定脉冲音；内容 CRC32 为 `5760d068`。

性能相关改动包括：AOT + O3/LTO；内部 RAM/PPU 寄存器直接访问；跳过绘制的帧只执行必要的 sprite-zero 检查，有特殊精灵 latch 的 Mapper 保留原遍历；60 Hz 模拟计时保留欠账，显示提交单独限速并遵守 Surface 背压。PAL 使用 50 Hz。

本地还修正了零页指针跨界、ANC carry、ATX、SHX/SHY 跨页行为、手柄 strobe、分数音频采样和字节安全的取字读取。完整清单位于 [upstream.json](nes-20261019/upstream.json)。

## 实机与测量方法

设备为 PAI Touch / ESP32-S3，序列号 `a4:cb:8f:d5:d4:f0`，本轮串口 `/dev/ttyACM1`。实际固件提供 Core 2.0、PXA 0.3.0、Clock 0.2、FS 0.2。应用协商兼容旧接口：默认 DISPLAY 1/4，屏幕缓冲忙碌时继续跳过显示；每个模拟帧仍执行 CPU、必要的 PPU 状态和 APU。

正式测试先确认设备解锁、实际显示应用、收到新的 `NES READY`，再启用音频、等待预热，订阅带版本号的实时 `NES PERF` 日志。统计使用应用本地单调墙钟和实际完成的帧数，而非时钟回调次数：`sim_x100 = frames * 100000000 / elapsed_us`，整数向下取整。测量窗口内不读写 flash，不截图、不查询内存；截图和内存快照在窗口外采集。

运行命令（先进入诊断 ROM，确保解锁）：

```sh
python3 local/pxa-apps/nes/tests/device_perf.py \
  --port /dev/ttyACM1 --output local/nes-work/acceptance-012/performance \
  --samples 4 --warmup 6
```

| 窗口 | 完成模拟帧 | 墙钟秒 | 模拟 FPS | Surface 提交 FPS | 窗口末欠账 | 音频丢采样 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 299 | 5.004792 | 59.74 | 8.99 | 1 | 0 |
| 2 | 301 | 5.032107 | 59.81 | 8.74 | 0 | 0 |
| 3 | 302 | 5.004573 | 60.34 | 8.59 | 0 | 0 |
| 4 | 300 | 5.032080 | 59.61 | 8.94 | 0 | 0 |

合计 **1202 帧 / 20.073552 秒 = 59.879786 FPS**。窗口末欠账最多 1 帧，没有增长趋势；应用音频环形缓冲丢弃采样为 0。内核每帧平均计算时间约 10.96–11.12 ms。Surface 提交是应用成功交给宿主的帧数，**没有测量 LCD 的光学刷新率**。

原始记录：[性能 JSON](nes-20261019/pai-touch-performance-012.json)、[串口日志](nes-20261019/pai-touch-performance-012.log)、[汇总](nes-20261019/pai-touch-summary.json)。旧版通过写 flash 性能文件取得的记录会干扰负载，未作为本轮验收依据。

## 模拟器及内核回归

先在桌面产品模拟器运行签名 AOT，再进行 PAI Touch 实测；最终版本又在独立的 `pai-touch@nes-test` 实例复核。最终模拟器观察到 PACK、SD、flash 三种来源各自的 `NES READY`，并拒绝截断文件。连续运行窗口约 59.90–59.98 FPS；切换 DISPLAY 1/2 后，模拟约 59.98 FPS、Surface 提交约 29.99 FPS。切换暂停菜单跨越的一个统计窗口包含暂停时间，单独保留，不计作连续运行窗口。[模拟器记录](nes-20261019/simulator-012.json)、[模拟器日志](nes-20261019/simulator-012.log)。

## 输入、声音、存档和内存

在真实设备上通过 PXADB 注入触控，按住虚拟 A 后诊断画面变红，释放和暂停均正常。截图仅用于确认行为，截图时的屏幕 FPS 数字不作为性能证据。

![PAI Touch：按住 A 后画面变红](nes-20261019/pai-touch-a-held.png)

音频为 16 kHz 单声道 PCM，权限获准后启用，256 ms Guest FIFO 重试短写和 WOULD_BLOCK。最终实时窗口丢采样为 0；停止时宿主报告 `active=1 submitted=21260 rendered=20355 rejected=0`，证明有实际音频数据被接受并渲染。宿主还报告多次 queue_full，重试由 Guest FIFO 承接。未进行人工听感、声学延迟或连续数小时测试。[停止及音频日志](nes-20261019/pai-touch-persistence.log)。

暂停触发 8192 字节电池 SRAM 原子保存；随后从设备读取存档，CRC32 `f236e69e` 与 `NES SRAM SAVED` 成功记录一致。应用停止并重新启动，再次观测到诊断 ROM 就绪，最后留在没有 SAVING 提示的暂停菜单。[存档校验](nes-20261019/pai-touch-persistence.json)、[重启记录](nes-20261019/pai-touch-restart.json)。这是电池 RAM 保存，不是任意时刻状态存档。游戏运行时不周期性写 flash；退出前应先暂停并等待 SAVING 消失。

![重新启动后停在暂停菜单](nes-20261019/pai-touch-restarted-paused.png)

应用线性内存初始值与最大值都固定为 4 MiB，并启用 pinned。旧设备在内存增长后会留下失效的 Surface 映射地址，固定内存后实机画面稳定。运行和停止后的系统内存快照如下；这些是整机可用内存，不是 Guest 独占用量。

| PSRAM 最大连续块 | 1,867,776 | 6,422,528 |
| 可用 SRAM | 34,451 | 37,187 |
| 宿主预算分配失败 / 拒绝 | 0 / 0 | 0 / 0 |

## ROM 使用和当前限制

- 当前 PAI Touch 的 FS 0.2 使用 flash。最方便的方式是把有使用授权的 `.nes` 放进 `local/pxa-apps/nes/assets/roms/`，重新构建安装，使用 PACK 页。FLASH 页也能枚举私有 `roms/`；本机旧 PXADB 禁止写该私有目录，因此实机使用签名包 assets。
- SD 路径已在桌面模拟器验证；实机需要提供 FS 0.3 应用媒体根的固件。对应本开发签名的路径是 `/PXA/media/f51ae392de0ca33cf8721d850d313d00911125b7796f3a456bde9ada789917fa/`。没有把模拟器通过写成实机 SD 已通过。
- 当前只枚举单层目录，最多 128 项、单文件最多 3 MiB。支持 iNES/trainer 和常用 Mapper；不支持压缩包、NES 2.0、FDS、NSF、VS/PlayChoice。菜单字体只显示 ASCII，建议英文文件名。
- 仍需按具体游戏测试正确性、复杂画面的满速能力、存档语义和长期稳定性。没有捆绑或下载商业游戏；不能由本轮诊断 ROM 数据推断所有游戏满速。

构建、放置 ROM、控制和回归命令见 `local/pxa-apps/nes/README.md`。构建日志与校验：[build.log](nes-20261019/build.log)、[安装包/AOT SHA256](nes-20261019/artifact-sha256.json)、[源码 SHA256](nes-20261019/source-sha256.json)。
