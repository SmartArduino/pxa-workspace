# PAI Touch：超级马里奥、重装机兵及颜色验证

## 实机帧率

设备是既有的 PAI Touch / ESP32-S3，序列号 `a4:cb:8f:d5:d4:f0`；固件仍为 Core 2.0、PXA 0.3.0、Clock 0.2、FS 0.2，没有更新固件或格式化存储。

正式 ROM 通过本地临时身份 `pxa-nes-games` 的签名 flash assets 加载。其前端和内核使用正式修正版源码，区别为包身份和 ROM 列表；线性内存同为固定 4 MiB。测试开启声音，预热后各采集四个完整窗口，按实际完成帧数除以本地单调墙钟时间计算。窗口内只读取实时日志并注入保持唤醒的输入，截图、存储查询和内存查询都在窗口外。

## 颜色对照

参考程序是本机 **FCEUX 2.6.6 / new PPU**，载入与 PXA 相同的 `Composite_Direct_FBX.pal`。已逐项确认独立安装的 FCEUX 调色板与内核默认表的全部 **64 个 RGB 三元组一致**。该表的来源说明见 [FirebrandX 的 Composite Direct 项目](https://www.firebrandx.com/nespalette.html)。

用 [FCEUX 官方 Lua API](https://fceux.com/web/help/LuaFunctionsList.html) 的 `gui.gdscreenshot(true)` 提取未滤镜的 256×240 参考帧。PXA 游戏区域为 `(58,0,179,168)`，按实际最近邻采样位置比对，排除顶部 20 行系统 FPS 遮罩。比较编码后的 RGB565，而非直接比较 PNG 的 RGB8：实机采用位复制扩展，桌面采用整数缩放，同一个 RGB565 值可能相差 1 个 RGB8 单位。

| 实机标题画面 | 比较像素 | RGB565 匹配率 | 调色板以外的像素 |
| --- | ---: | ---: | ---: |
| 超级马里奥 | 26,492 | **100%** | 0 |
| 重装机兵中文版 | 26,492 | **100%** | 0 |

这验证了所测静态画面的调色板索引、属性配色、RGB565 转换和颜色通道顺序。对比对象为选定的同一调色板；真实电视的模拟解码和 LCD 的物理色温不在本次数字截图比较范围内。NES 模拟信号到 RGB 本身存在显示设备与解码差异，背景说明见 [NESdev PPU palettes](https://www.nesdev.org/wiki/PPU_palettes)。

## 测试发现和修复

0.1.12 在真实 ROM 上暴露出诊断 ROM 未覆盖的问题：马里奥约 45.48–46.70fps、积压从 47 增至 102 帧；重装机兵起名画面约 58fps，也有积压。因此没有把之前诊断 ROM 的约 60fps 扩展成所有游戏的结论。[马里奥基线](nes-games-20261020/baseline-mario-012.json)、[重装机兵基线](nes-games-20261020/baseline-metal-012.json)。

0.1.13 修复了两处前端问题：

1. **调度预算。** 重游戏的一帧会超过旧 12 ms 预算，导致每次回调总是只做一帧、无法追赶。改为在完整帧后检查 24 ms 预算，每次最多追赶四帧；积压达到两帧时进一步压低显示频率，至少间隔 250 ms 才尝试绘制，不丢弃模拟时间。
2. **底部触控。** 原上/下方向键和 MENU 位于系统底部手势区，输入被宿主截获。按钮整体上移，为底部保留 24 像素；已在模拟器和实机通过起名键盘与移动操作复核。完整游戏画面按比例缩放到控制区上方。

新增颜色对比工具 `local/pxa-apps/nes/tests/compare_colors.py`；性能采样器增加 `--hz 50` 和 `--app-id`，可以正确验收 PAL 和临时测试身份。内核、默认调色板和 ROM 内容没有为本轮测试修改。

## SRAM、声音、内存和设备收尾

重装机兵暂停后从设备读回 8192 字节电池 SRAM，CRC32 `1c9a0deb` 与成功原子替换日志一致。[SRAM 校验](nes-games-20261020/sram-verification.json)。这验证前端保存完整性，不等于完整的游戏内存档流程验收。

停止时宿主音频计数为 `submitted=54861 rendered=51277 rejected=0`；正式窗口中 Guest 丢采样为 0。[音频及保存日志](nes-games-20261020/sram-and-audio.log)。未进行声学延迟或人工听感测量。

运行重装机兵且启用声音时，整机可用 PSRAM 为 2,203,404 字节，可用 SRAM 为 34,451 字节；宿主预算分配失败和拒绝均为 0。这些是系统快照，历史最低内存不限定于本次游戏。[运行快照](nes-games-20261020/memory-active.json)、[停止后快照](nes-games-20261020/memory-stopped.json)。

临时测试身份已停止并卸载；正式 `pxa-nes` 升级为 0.1.13，最后重新启动随包诊断 ROM，通过新位置的 MENU 触控按钮停在暂停菜单，声音关闭。原有浏览器及正式应用私有目录保留。[最终设备状态](nes-games-20261020/final-device.json)。

正式包路径为 `local/app-output/pai-touch/pxa-nes.pxa`；用户游戏的临时测试包保存在本地忽略目录 `local/nes-work/games-20261020/package-final/`。正式源码的 ROM assets 仍为自行生成的诊断程序。当前实机 FS 0.2 使用 flash；SD 的实机限制与此前一致。

## 重现与证据

性能验证（先启动目标游戏并启用声音）：

```sh
python3 local/pxa-apps/nes/tests/device_perf.py \
  --port /dev/ttyACM1 --app-id pxa-nes-games --hz 50 \
  --samples 4 --warmup 8 --output local/nes-mario-perf
# 重装机兵使用 --hz 60；正常安装身份默认是 pxa-nes。
```

颜色验证示例（`mario.gd` 为上述 FCEUX API 的原始输出）：

```sh
python3 local/pxa-apps/nes/tests/compare_colors.py \
  --reference-gd mario.gd --screenshot pai-mario.png \
  --palette /usr/share/fceux/palettes/Composite_Direct_FBX.pal \
  --area 58 0 179 168 --ignore-top 20 --output colors.json
```
