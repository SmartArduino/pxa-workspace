# Korvo 设置列表底部布局（2026-10-20）

设置及其子页的滚动视口现在延伸到屏幕安全边界的底部，不再为手势导航永久
裁掉一条空白区域。左右卡片间距、顶部状态栏及手势操作保持原有布局。
末项的避让空间放在可滚动内容的底部 padding 中，滑动中内容可以绘制到底边。
这项修改使用现有 LVGL 对象，不增加任务、帧缓冲或 ABI。

修改位于 SDK `4739c32` 的 `ui/reference/lvgl/src/reference_lvgl.c`，应用于手势导航的原生
设置页面；启动器网格和三键导航保持原布局。

实机为 `esp32s31-korvo-1`，MCU `30:ed:a0:f3:de:10`，800×480：

- 固件编译及 codec 内存审计通过。
- 刷写前读取当前固件并验证原镜像校验和、SHA-256；新旧分区表逐字节一致。
- 仅刷入 `0x10000` 应用镜像，esptool 完整校验通过。
- 新应用 SHA-256：`23dea7af13bc78ffc1aebc364b21847b5ca46bba159a788bdec6c9c26b647329`。
- 新 ELF SHA-256：`f4e11668370165318f033437578b9a9003c1a7c33b20620361cc795f661a488b`。
- 设置实机截图显示“声音与显示”卡片绘制到底边，没有原来的固定底部裁剪区域。
- 滚动后“应用”“文件与存储”“关于设备”均可显示。
- 从底边上滑，等待动画完成并强制获取下一次显示结果，截图确认返回启动器。
- 原生 reference feature masks 测试在内置设置关闭、开启两种配置下通过。
