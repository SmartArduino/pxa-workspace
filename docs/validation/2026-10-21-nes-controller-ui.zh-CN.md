# NES 手柄菜单验收：0.1.37 / release 43

本次适配 NES 内的界面，保留现有中文/英文与分辨率适配。代码主要位于 `local/pxa-apps/nes/menu_controller.h`、`main.c`、`slots.h`，安装包为 `local/nes-controller-ui-20261021/package/pxa-nes.pxa`。S31 和桌面模拟器 AOT 均已构建。

## 操作

- 方向键上下选择游戏、暂停选项和即时存档；在列表末尾向下可进入底部按钮，底部左右切换，上键返回列表。游戏列表第一项按上也可快速到达“刷新”。
- A 确认，B 返回；游戏库的 B 为正常退出，会沿用等待 SRAM 写入完成的退出流程。Y 快捷刷新游戏库。
- X 暂停/继续；即时存档页的 X 仍为快捷新增。空游戏库可聚焦刷新与退出，空存档页默认聚焦新增，也能选择返回。
- 按住方向键 350 ms 后，每 90 ms 移动一项，不因一次慢 I/O 累积多个跳步。松开、断连、后台或触摸操作后停止重复。菜单方向焦点由第一手柄控制，第二手柄的游戏输入保持支持。
- 底部焦点使用亮色高亮；焦点移到底部后游戏列表不再显示活动选择箭头。确认菜单操作的事件不直接写入游戏 pad 状态。

重复处理和菜单导航均为冷路径，只有 `mode != PLAYING` 的分支才运行菜单重复检查。没有新增游戏帧计时器、帧缓冲或逐帧 UI 布局。

## 软件与设备测试

前端原生回归通过：游戏库/底部/空列表焦点、确认与返回、第一手柄焦点、菜单长按、跨缓存边界存档导航；原有语言、缩放、系统字体、滚动、音频权限/错误恢复、退出等待 SRAM 测试继续通过。

设备为 DOIT GameKit-1，ESP32-S31，序列号 `1c:29:04:d0:af:6a`。使用控制器事件注入，经实际 Host/Guest 路径验证；不将其称为机械按键按压测试。本次未刷固件。

实机截图及像素核对确认“刷新”“退出”“新增存档”“返回”均能聚焦；长按可滚到第九个游戏并进入底部。“退出”确认前应用 active=1，A 确认后 active=0，正常返回系统桌面。首轮受桌面切换影响的刷新/退出检查已重测，未将桌面截图当作应用内焦点通过证据。

马里奥 mapper 0、PAL 50 Hz，开启声音并持续 RIGHT/A 输入，采集四个完整窗口：

| 指标 | 结果 |
| --- | --- |
| 模拟速度 | 49.97、50.13、49.92、50.05 Hz |
| 模拟积压 | 四窗均为 0 |
| LCD 完成频率 | 44.859 FPS |
| 音频 | 四窗 sound=1；丢弃采样 0、64、0、0 |
| 悬浮键 | 四窗自动隐藏 |

上一版 0.1.36 的同 ROM 参考 LCD 频率为 45.151 FPS；本次差异约 -0.65%，动态场景不同，观察到的帧率基本持平，不声称严格零损耗或无音频丢弃。LCD 指标为固件完成提交频率，未当作光学面板刷新率。锁屏期间没有新鲜 NES 采样的一组记录已排除；另一次 LOGSUB 超时也未计作有效性能结果。
