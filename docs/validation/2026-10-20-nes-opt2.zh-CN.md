# PXA NES：第二轮应用性能优化

最终版本 **0.1.19 / release_sequence 20**。本轮比较同一 PAI Touch 上重新运行的 0.1.18 与 0.1.19，保留全屏、原调色板、半透明按键、声音、手柄隐藏和电池 RAM 保存；未刷写固件。

## 改动

- 脏图块由每缓冲 960 字节标记改成 30 个 32 位位图。相邻变化块合并成连续行段；某个 8 行区域的两张缓冲都已全部失效时，后续变化行只更新历史图像，省去重复的逐图块判断。元数据减少 2,528 字节。
- 对齐的历史图像比较使用 64 位载入，保留 4 字节和非对齐回退；按键区域也成对写入 RGB565，减少 Guest 写入检查。新游戏完整重绘时取消多余的整帧清零。60 KiB 历史图像仍放在预留输出数组的闲置尾部，Guest 线性内存仍固定为 4 MiB。
- CPU 读取普通映射页时，检查实时页标记后直接读取，省去通用总线函数调用。有读处理器、未映射页仍走原路径，不缓存映射，保留 Mapper 改页和读副作用。
- OAM DMA 对低地址、已映射且没有读处理器的页使用批量复制，保留 OAM 地址回绕及原停顿计数。I/O、Mapper 处理器和特殊映射继续读取原总线；没有扩大到无条件复制任意 CPU 地址。

现有 GuestMapped Surface 和提交协议不变：提交的是完整逻辑帧的缓冲索引和帧号，没有整帧 Guest→Host 复制。本轮减少 Guest 扫描、转换和绘制工作，Host 的旋转与 LCD 传输仍存在，不是端到端零拷贝。相关链路说明见[上一轮报告](2026-10-20-nes-render.zh-CN.md)。

## 实机方法与结果

设备为 PAI Touch / ESP32-S3，序列号 `a4:cb:8f:d5:d4:f0`，PXA 0.3 / Core 2 / Clock 0.2 / FS 0.2。对照使用相同 ROM、相同进入游戏的短操作流程，开启声音，铺满 296×240，默认 DISPLAY 1/4，按键不透明度 3/8；另测隐藏按键。马里奥持续右+A工况使用同一指针脚本。

每个工况重启应用，预热 8 秒后采集三个完整约 5 秒的遥测窗口。采样器按 `wall_us - elapsed_us` 过滤，排除跨越预热边界的窗口。LCD 探针从预热前开始，结束于遥测采样完成，窗口包含预热，与三段遥测的分母不同。截图、存储和内存查询都在探针停止后执行。

LCD 完成 FPS 使用 `PERF START display` / `PERF STOP` 的 `display=1` 与 `completed × 1e6 / window_us`；这是全帧 DMA 传输完成频率，包括相同内容的重复传输，不是面板内部扫描 Hz、光学测量或独立画面变化计数。Surface 提交频率单独列出。

| 马里奥初始场景 | 0.1.18 | 49.926 | 6.843 | **6.788** | 16.268 | 5.726 |

内核调用和绘制时间都是单调墙钟平均值，包含可能的宿主抢占，不是硬件周期计数。LCD 完成频率在此短测中的提升为 马里奥初始场景 12.5%、马里奥持续右+A 14.4%、重装机兵初始场景 6.2%。[前后原始数据](nes-opt2-20261020/comparison.json)、[最终五个工况](nes-opt2-20261020/device-summary.json)。

继续使用 FCEUX 2.6.6 / new PPU 和 Composite Direct FBX 调色板参考，比较编码后的 RGB565。实机排除顶部 20 行宿主 FPS 覆盖，显示按键时排除控件区域；桌面另排除圆角和手势提示条。马里奥参考与采集时序的金币闪烁可能造成少量差异；这不是 LCD 光学校准。

- 新旧视频输出与独立完整绘制参考逐像素相等，覆盖 **6,240 帧**，包括 8/4/1 字节对齐、四种尺寸、两张缓冲、缓存关闭、变化抵消、控件状态、失效恢复；普通及 ASan/UBSan 均通过。
- **144 个 DMA 用例**覆盖所有内部 RAM 镜像、重新映射、OAM 回绕、原 513 周期停顿，以及 RAM/I/O 处理器逐次读取。另验证 ROM/SRAM 读处理器不会被直接读取旁路绕过；普通及 ASan/UBSan 均通过。
- **25 项内核对照**包含 16 个 Blargg 独立指令 ROM、PAL、trainer 和六类 Mapper 启动/输入，与保留原总线和精灵扫描的参考实现具有相同 CPU、RAM、视频签名。**9 项 ASan/UBSan 内核用例**通过。此前组合版 `official_only.nes` 未通过的限制没有因此解除。
- 桌面再次通过方向+A、手柄操作自动隐藏、释放保持隐藏、触控恢复、X 暂停和纯手柄菜单。输入来自 SDL 键盘到标准 controller-state 事件，本轮没有新测 GameKit 实机运行速度、机械按压或蓝牙/USB 外接手柄连接，也没有物理测量输入到屏幕发光的延迟。

## 宿主 INDEX8 路径的限制

实机明确报告 GameRender **0.6，features=1**，本地 SDK 的借用 INDEX8 接口要求 GameRender **1.0**。兼容性检查拒绝了该服务要求，不能把新 Host 代码已经存在等同于实机已经提供此能力。[实际兼容性日志](nes-opt2-20261020/game-render-compatibility.txt)。最终应用没有依赖此服务，保持在原固件上运行。

现有 Host blit 还采用固定 320×240 的中间采样网格，直接用于 NES 的 256→296 缩放会改变取样位置。将来接入时需要保留精确采样和按键混合，再验证颜色；本轮没有声称已经合并 Host 的转色、缩放与旋转，也没有声称原生直刷逐帧命中或 LCD 达到 60fps。

## 内存、存档与交付

重装机兵开启声音的窗口外快照：PSRAM 可用 2,131,164 字节，SRAM 可用 34,451 字节；预算拒绝 0，分配失败 0。完整[内存记录及累计边界](nes-opt2-20261020/device/metal-max-cn/on/performance/memory.json)。相同工况旧版 PSRAM 可用 2,197,448 字节；新版快照减少 66,284 字节。Guest 元数据缩小并不意味着整机用量同步下降，内核内联增加 AOT 代码驻留开销，快照还受宿主状态影响。Guest 音频丢采样统计见各窗口，声音未做人工听感或声学延迟测量。

重装机兵 8,192 字节电池 RAM 文件 CRC 与成功保存日志一致。[保存检查](nes-opt2-20261020/persistence-final.json)。临时探针、0.1.18 对照与 0.1.19 测试身份均已停止并卸载；原正式 `pxa-nes` 保留私有数据并更新到 0.1.19，原浏览器保留。最终运行正式包自带原创诊断 ROM 后暂停，声音关闭。[最终设备状态](nes-opt2-20261020/final-device.json)。

自行启动的模拟器及调试服务均已停止。模拟器清理用 SIGTERM 后仍返回 134，服务返回 0，与上一版一致；没有将自然关闭计为通过。[桌面收尾](nes-opt2-20261020/simulator-cleanup.json)。设备停止、更新和重新运行通过。

正式包：`local/app-output/pai-touch/pxa-nes.pxa`，仅含原创 CC0 诊断 ROM。用户商业 ROM 只在本地忽略目录的临时签名包中，没有复制到正式包或报告附件。见[包校验值](nes-opt2-20261020/artifacts.json)、[正式/测试前端源码一致性](nes-opt2-20261020/frontend-identity.json)、[原 ROM 未改动校验](nes-opt2-20261020/rom-integrity.json)。
