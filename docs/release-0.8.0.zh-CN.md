# PXA 与官方板级固件 0.8.0

本版固件内嵌 PXA 0.8.0、Core 2.1、UI 0.10，预装商城 0.9.3 / sequence 33。
Guest C/C++ SDK、DevKit、模拟器与 PXADB 同步发布为 0.8.0。

## 主要变化

- 增加系统字体字形读取接口和 C/C++ 封装，提供字形基线、度量与有界覆盖位图。
  Host 字体栅格化工作内存增加明确上限，避免大字号导致瞬时分配失控。
- 商城自更新在下载和批准后移交给 Host：停止旧商城激活并等其存储租约释放，再提交更新。
  修复商城占用自身安装目录导致更新失败；失败时保留可恢复的应用和私有数据。
- 修复旧 `pxa-state` 安装和预装商城的原位更新路径，签名覆盖版本继续使用原私有数据。
- PXADB 更新保留已有应用的安装卷，防止更新意外产生另一个安装位置。
- 商城下载期间临时保持 Wi-Fi 活跃，结束和失败时恢复原省电策略。
- 修复 ESP 目录操作重入死锁，构建许可证检查等待生成源码完成后再审计。
- 浏览器运行时 0.7.7 已独立提供透明 UI、原生联网、音频和传感器等改进；本次不更换其版本。

Core 与 AOT ABI 不变。使用新字体接口的应用需声明 UI 0.10 及功能位；旧应用继续按
实际 Host 能力检查。固件、PXA、商城各自编号，不能用整机固件号代替应用兼容性判断。

## 下载与升级

- [SDK、DevKit、模拟器与主机工具](https://github.com/SmartArduino/pxa-system/releases/tag/v0.8.0)
- [六种官方板型固件](https://github.com/SmartArduino/pxa-workspace/releases/tag/v0.8.0)

支持 pai-touch、esp-mosaico、esp32s31-korvo-1、sensecap-watcher、doit-gamekit 和 doit-gamekit-1。
各板分别提供首次安装的合并镜像、保留数据升级的应用镜像、分区文件及刷写说明。
Watcher 为 32 MiB Flash，其余五板为 16 MiB；不能跨板型混刷。

分区布局一致时仅更新 app 镜像可保留已安装应用、存档和设置。合并镜像会重写数据分区，
用于首次安装或明确清除数据的重装。Korvo 和 Mosaico 的旧 4 MiB app 分区迁移仍须遵守
[历史分区迁移说明](release-0.6.0.zh-CN.md)，不能把新版 app 镜像写入旧布局。
完整镜像预装商城；保留数据升级仍保留原商城，升级后联网打开它检查更新。

本次发布按六板交叉构建、Host 回归、安装包/工厂镜像校验及桌面消费测试验收。
交叉构建不等于六板全部完成真机验证，商城自更新修复的新固件真机验收仍待完成。
