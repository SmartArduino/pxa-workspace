## 中文

PXA <版本>：说明解决的问题与用户能做的事情。

- 下载与安装：固定版本的 DevKit 链接、平台与最低系统要求。
- 兼容性：Guest Core、服务与 AOT ABI；破坏性变化和迁移方法。
- 验证：实际执行的构建、模拟器、真机与部署检查。
- 限制：尚未覆盖的平台或场景；不把推测写成实测收益。

## English

PXA <version>: describe the concrete problem and resulting user behavior.

- Download and install: pinned DevKit link, supported platforms and minimum OS requirements.
- Compatibility: Guest Core, services and AOT ABI; breaking changes and migration.
- Validation: builds, simulator/device checks and deployments actually completed.
- Limitations: uncovered platforms or scenarios; distinguish measurements from expectations.
