# 流式 HTTP 调度与浏览器验证（2026-10-14，后续迭代）

本次在[首轮流式 HTTP](pxa-http-stream-validation.zh-CN.md)基础上减少空闲调度等待，并交付
C++26 小舟浏览器。明确的收益是桌面模拟器更及时地消费数据，以及浏览器可提前读取响应头、
有界解析正文。ESP32-S3 上大正文总耗时仍比旧缓冲路径长；没有据此宣称游戏帧率提升。

## 采用的调度改动

| 原因与改动 | 实测或预期收益 | 内存变化 | 验证 |
| --- | --- | --- | --- |
| 桌面主循环原先在网络进展后仍无条件 SDL_Delay；等待已有交换的 condition，并由网络进展中断 | 同一 1 MiB 功能负载完成由 526/595 ms 降至 86/90 ms；这两次运行包含调度变更，不是统计充分的 A/B | 复用已有 mutex/condition；新增标志占 64 位结构原有 padding，backend 仍 104 B | 原生背压、取消、关闭/退出、两项桌面回归；真实 Wasm/AOT 应用完整通过 |
| ESP 网络线程满环后原先延迟一 tick；消费释放空间、空上传环得到数据及关闭时通知现有线程 | 消除可避免的一 tick 等待；本轮 ESP 总耗时数据不支持吞吐改善的结论 | 不增加线程、栈、环形缓冲或槽位；使用现有任务通知 | 512/4096 B 满环、唤醒和关闭回归；两轮同启动交替下载全部逐字节通过 |
| 自绘 UI 需要准确避开系统左侧返回手势 | 修正 Host 发布的左 inset，包含实际输入条覆盖的 safe margin；避免图标点不到 | 仅修正数值，无新状态/缓冲 | pai-touch 导航、输入、表单与菜单操作，六种模拟器屏幕 |
| Canvas 坐标为 dp，DisplayMetrics 为屏幕像素 | 新增可选的反向坐标/裁剪转换与交互安全矩形；分数 DPI 下绘图和触摸一致 | 内联无状态函数，无默认分配/缓存 | C++26 ASan/UBSan 几何测试及实际 AOT 截图 |

桌面等待只能由拥有 backend 的线程调用；关闭和 shutdown 仍由同一线程执行。完成事件发布后
再标记 worker 退出，避免主线程提前释放交换。多个交换的网络进展都会唤醒等待者，防止等错请求。
无活跃流式交换时保留原有主循环等待。此处没有新增跨 Wasm 零拷贝，也没有新增导入函数。

尝试将 ESP 正文读取超时从 50 ms 缩至 1 ms，没有取得可靠的总耗时收益，最终撤回。
最终保留 50 ms、每步最多 4 KiB，避免用更频繁的空轮询换取未经证实的收益。

## 同负载复测

同一 pai-touch、局域网服务、256 KiB 字节校验、固定 80 ms 首块延时、O3。
每次启动先预热一对，再交替运行旧、新各六次，两次启动共各 12 个有效样本。
两条路径在同一个包中，正文总量、内容和 UI 相同。

| 路径 | 响应头中位数 ms | 首块中位数 ms | 完成中位数 ms |
| --- | ---: | ---: | ---: |
| 旧缓冲 | 990.5 | 991 | 1101.5 |
| 4 KiB 流式 | 36.5 | 159 | 1419 |

流式响应头提前约 96.3%，首块提前约 84.0%，总耗时增加约 28.8%。无线波动明显，
不能把这个百分比与首轮报告的 10.4% 差异都归因于通知改动；没有做通知前后同无线条件的受控 A/B。
原始交替计时见 [results.json](benchmarks/http-stream/2026-10-14-notify/results.json)。

桌面原生同负载单次结果：旧路径首块/完成 83/85 ms，新路径响应头/首块/完成 1/82/83 ms。
1 MiB 流式已知长度完成 87 ms，慢消费者 chunked 完成 652 ms；正文驻留 4096 B，
交换统计存储 5320 B。重复响应头、100 KiB 上传、满环取消、超预算、重定向交回 Guest、
提前拒绝上传和矛盾 framing 均通过。这些不是 ESP 性能数据，也不能与不同正文大小横比。

## 内存与复现

首轮独立包的真实局部峰值对比仍见原报告：256 KiB 下载 PSRAM 峰值减少约 245–250 KiB，
预热后的 SRAM 峰值相当。后续交替包的局部峰值混合了两条路径，不能用于各路径峰值比较。
本次调度修改没有增加环、库接收缓冲、请求槽或线程栈；桌面 backend 的实际编译布局为
104→104 B。SDK 几何函数仅在调用时编译使用，不为其他应用增加默认开销。

测试命令沿用原报告。新增原始证据位于
[后续验证产物目录](benchmarks/http-stream/2026-10-14-notify/results.json)，包含原生/模拟器日志、
两轮交替记录、布局及最终浏览器固件 SHA-256。交替测试使用通知改动固件；随后只修正 UI inset
发布并再次构建、刷写 factory 分区。没有更改分区表、NVS、应用数据或持久设备设置。

浏览器的公网 HTTPS、搜索、系统输入、页面显示、实际运行内存及屏幕矩阵，记录在
[浏览器报告](../local/pxa-apps/browser/docs/validation-20261014.zh-CN.md)（文件属于 pxa-apps 仓库）。
本报告中的下载例程和浏览器不是游戏负载，没有测量或推断游戏 FPS 收益。
