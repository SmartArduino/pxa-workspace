# pxa_board_common

Board-side code that more than one ESP board profile shares. It exists so a new
board starts from the same shell instead of copying the previous board's
`.cc` file: geometry, backlight/screen policy, status publishing, Wi-Fi
control, touch slot bookkeeping and the PXADB control adapters belong here as
they are extracted.

Every board with gamepad input follows the shared reference-UI lock policy:
call `pxsys_reference_lvgl_handle_gamepad()` each poll before shortcuts, focus
navigation and game input. While it consumes input, clear focus, hide the cursor
and report zero buttons for physical and injected controllers. Any fresh button
press unlocks an already-lit lock screen; hold,
chord and release events from that sequence cannot reach the resumed UI or game.
An already-held sequence must be released before it can unlock. Keep touch-only
lock-screen gestures available when the gamepad is idle.
The board must consume a sleeping screen's wake sequence, including its release,
before calling this policy. Wake and unlock require two separate presses.

What deliberately stays in `firmware/boards/<board>/`:

- panel and controller bring-up, vendor init tables and their shims,
- presenters and every DMA/PSRAM hot path (`parallel_sw_rotation_flush.h`,
  `*_pxa_surface.cc`, `te_sync_panel.cc`, flush tasks),
- power sequencing (rail latches, amplifier pins, ADC calibration),
- vendored third-party code,
- `sdkconfig.defaults`, `partitions.csv`, `board.cmake`, `idf_component.yml`,
- the `pxa_board_register_selected()` definition, generated by
  `PXA_BOARD_REGISTER_SELECTED()` in the board's own translation unit.

Keep this component dependency-light: every directory under
`firmware/components/` takes part in dependency resolution for *every* board,
so packages such as `espressif/button`, `espressif/esp_codec_dev` or
`espressif/adc_battery_estimation` stay in opt-in satellite components rather
than here.

`rgb565_rotation.h` supplies tiled 90/270-degree wire conversion, integer scaling
and inverse capture for SPI boards. `surface_rgb565_rows.h` copies unscaled opaque
Surface rows and clips alpha-plane work to their intersections; region masks and
other formats retain the board fallback. These helpers borrow frame pixels only
for the duration of the existing Surface lease.

`lcd_render_trace.h` reports LVGL render/draw, composition, copy, output-buffer
wait, rotation and drained SPI transfer times when the existing Performance log
setting is enabled. Logging off avoids timer reads in the display hot path.
